# **🐺 Fightcade Plus (Cerberus)**

**Desenvolvido com foco em alta performance e otimização para todos os PCs.**  
O **Fightcade Plus** é um script de aprimoramento (mod) para o cliente oficial do Fightcade. Ele injeta funcionalidades de qualidade de vida (QoL), filtros avançados e um sistema de reputação comunitária, tudo isso sem causar lentidão ou queda de FPS durante as suas partidas.

## **✨ Funcionalidades**

1. **Entrada automática em canais (Auto Join):** O Fightcade entra automaticamente na sua sala principal ao abrir.  
2. **Filtro Geográfico de Países:** Esconda jogadores de regiões distantes com um clique. Resiliente a jogadores offline e totalmente reativo.  
3. **Melhorias visuais no chat:** Veja o Ping exato (em números), Bandeiras, Ranks e Status (Online/Ausente) diretamente no chat da sala.  
4. **Sistema de Reputação Global (👍/👎):** Destaque jogadores com boas conexões ou oculte jogadores tóxicos/lagados de toda a interface do Fightcade.  
5. **Modo de Privacidade:** Aplique desfoque (Blur) em mensagens específicas ou no chat inteiro para evitar distrações enquanto joga ou transmite.  
6. **Desbloqueio de Temas Premium:** Acesso imediato a paletas de cores e temas exclusivos da interface (como o modo *Bretema*).

## **🚀 Como Instalar (Versão Simplificada)**

Para facilitar, disponibilizamos uma versão do Fightcade pronta para uso (Plug & Play), já com as otimizações do Cerberus aplicadas.

1. Acesse a aba de [**Releases (Versão Mais Recente)**](https://github.com/Cerberus-BR/FightcadePlus/releases/latest).  
2. Baixe o arquivo comprimido (.zip ou .rar) listado nos *Assets*.  
3. Extraia a pasta para o seu computador.  
4. Abra o executável do Fightcade normalmente e divirta-se\!

### **Instalação Manual (Para utilizadores avançados)**

Se você sabe o que está fazendo e quer injetar o script na sua própria instalação limpa do Fightcade, basta baixar o arquivo cerberus.js deste repositório e utilizá-lo para substituir o script original na pasta de plugins do seu emulador.

## **⚙️ Como Usar**

Uma vez dentro de uma sala de jogo (ex: KOF 2002, Street Fighter III), olhe para o canto superior direito da janela de Chat, ao lado do número de jogadores online.  
Você verá um ícone de engrenagem (⚙️).  
Clique nele para abrir o **Painel do Cerberus**. Lá, você pode:

* Mudar o idioma (Inglês, Português, Espanhol).  
* Ligar/desligar todas as modificações visuais.  
* Configurar os países permitidos no filtro.

Para usar a **Reputação**, basta passar o mouse sobre o nome de um jogador na lista lateral ou no chat, e um menu flutuante aparecerá para você Avaliar (👍), Negativar (👎) ou Limpar (🧹) o status do jogador.
